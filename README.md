## Firebase Setup

1. Создай проект в [Firebase Console](https://console.firebase.google.com/)
2. Добавь Android-приложение с package name `org.messenger.app`
3. Скачай `google-services.json` и положи в `composeApp/google-services.json`
4. Для бэкенда: скачай Service Account Key и настрой переменную окружения `FIREBASE_CREDENTIALS_PATH`
